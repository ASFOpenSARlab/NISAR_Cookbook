Basic Polarimetric Techniques with PolSARtools



This notebook introduces basic polarimetric analysis using NISAR quad-polarization GSLC (Geocoded Single-Look Complex) products and polSARtools. Full-polarimetric GSLC data contain complex measurements from the HH, HV, VH, and VV polarization channels, enabling analysis of different scattering mechanisms. Using polSARtools, this notebook utilizes both scene-wide and subsetted examples to demonstrate how to:

  • extract the C3 covariance matrix

  • apply a Refined-Lee speckle filter

  • create a Pauli decomposition RGB composite

  • create a HH/HV/VV RGB composite

This example uses NISAR GSLC products, which provide geocoded complex SAR imagery suitable for polarimetric analysis and other advanced SAR applications. For more information on NISAR GSLC data, refer to the NISAR Data User Guide.

2b. Retain only the URL for the most recent version of each product in the search results¶

Data is occasionally re-released with an updated version. Versions are recorded as a Composite Release Identifier (CRID) in a product’s filename. We can use the CRID to retain only the most recent version of each product in the list of URLs.

import re

if len(hdf5_urls) == 1:
    print("Single GSLC product found. Skipping CRID filter.")
    
else:
    pattern = re.compile(
        r"(NISAR_L2_PR_GSLC.*?)_P([0-9]{5})_N_F_J_[0-9]{3}\.h5$")

    latest_version_dict = {}

    for url in hdf5_urls:
        fname = url.split("/")[-1]

        match = pattern.search(fname)

        if not match:
            print(f"No match: {fname}")
            continue

        product, crid = match.groups()

        if (
            product not in latest_version_dict
            or crid > latest_version_dict[product][0]
        ):
            latest_version_dict[product] = (crid, url)

    hdf5_urls = [item[1] for item in latest_version_dict.values()]

print(f"Retained {len(hdf5_urls)} GSLC products:")

4. Extract C3 Covariance Matrix¶

NISAR GSLC products can be represented in several polarimetric matrix formats. In this notebook, we’ll extract the C3 covariance matrix, which contains the information needed to create both the Pauli RGB decomposition and the HH/HV/VV RGB composite.

Creating the C3 matrix directly from a GSLC with PolSARtools provides more control over processing choices such as multilooking and filtering. However, PolSARtools does not apply NISAR’s radiometric terrain correction when creating the matrix. If RTC is an important part of your analysis, consider using a GCOV product or manually creating a C3 matrix.

More about the C3 covariance matrix

The C3 covariance matrix is derived from the full-polarimetric scattering matrix and organizes the information from the HH, HV, and VV polarization channels into a 3 × 3 covariance matrix. In addition to preserving the scattering information from each channel, it describes how the polarization channels are related to one another, providing a more robust description of the scattering behavior that is less sensitive to random noise. This matrix serves as the foundation for several polarimetric processing techniques, including speckle filtering, visualization, decomposition, and classification.

The C3 covariance matrix has the following structure:

C3=[C11C12C13C12∗C22C23C13∗C23∗C33]\mathbf{C}_3 = \begin{bmatrix} C_{11} & C_{12} & C_{13} \\ C_{12}^{*} & C_{22} & C_{23} \\ C_{13}^{*} & C_{23}^{*} & C_{33} \end{bmatrix}C3​=⎣⎡​C11​C12∗​C13∗​​C12​C22​C23∗​​C13​C23​C33​​⎦⎤​
(1)

The diagonal elements (C11C_{11}C11​, C22C_{22}C22​, and C33C_{33}C33​) describe the strength of the polarization components, while the off-diagonal elements describe the relationships between them. The ∗^{*}∗ indicates the complex conjugate of the corresponding element.

The C3 matrix can also be viewed in terms of the polarization combinations used to form it. Below, each C3 element shows either the strength of an individual polarization component or the relationship between two polarization components. The lower off-diagonal elements are complex conjugates of the corresponding upper elements.

C3=[⟨HH HH∗⟩⟨HH HV∗⟩⟨HH VV∗⟩⟨HV HH∗⟩⟨HV HV∗⟩⟨HV VV∗⟩⟨VV HH∗⟩⟨VV HV∗⟩⟨VV VV∗⟩]Black: Off-diagonal covariance termsGreen: Diagonal termsLight gray: Complex conjugates of the corresponding off-diagonal terms\mathbf{C}_3 = \left[ \begin{array}{ccc} \color{green}\langle HH\,HH^* \rangle & \langle HH\,HV^* \rangle & \langle HH\,VV^* \rangle \\[6pt] {\color{lightgray}\langle HV\,HH^* \rangle} & \color{green}\langle HV\,HV^* \rangle & \langle HV\,VV^* \rangle \\[6pt] {\color{lightgray}\langle VV\,HH^* \rangle} & {\color{lightgray}\langle VV\,HV^* \rangle} & \color{green}\langle VV\,VV^* \rangle \end{array} \right] \\[12pt] \textcolor{black}{\text{Black}}:\ \text{Off-diagonal covariance terms}\\ \textcolor{green}{\text{Green}}:\ \text{Diagonal terms}\\ \textcolor{lightgray}{\text{Light gray}}:\ \text{Complex conjugates of the corresponding off-diagonal terms}C3​=⎣⎡​⟨HHHH∗⟩⟨HVHH∗⟩⟨VVHH∗⟩​⟨HHHV∗⟩⟨HVHV∗⟩⟨VVHV∗⟩​⟨HHVV∗⟩⟨HVVV∗⟩⟨VVVV∗⟩​⎦⎤​Black: Off-diagonal covariance termsGreen: Diagonal termsLight gray: Complex conjugates of the corresponding off-diagonal terms

5. Reduce Speckle with a Refined Lee Filter¶

Before creating RGB composites, apply the Refined Lee filter to reduce speckle while preserving important scattering features such as edges and boundaries. The implementation used by polsSARtools applies the same filter to all covariance terms, which is important for preserving the relationships between them while maintaining the ability to make relative comparisons between terms.

More about the Refined Lee Filter

The Refined Lee filter reduces speckle by analyzing the statistical properties of pixels in a local neighborhood. Rather than applying a fixed level of smoothing, it adjusts amounts of smoothing based on local image characteristics. The Refined Lee filter applies more smoothing in homogeneous areas while preserving edges, boundaries, and other important scattering features.

C3Folder = os.path.join(in_file.split(".h5")[0], "C3")

window_size = 3

pst.filter_refined_lee(
    C3Folder,
    win=window_size,
    fmt="tif",
    sub_dir=True,
    cog=False,
    ovr=[2, 4, 8, 16],
    comp=False
)

6. Create a Pauli RGB Composite¶

The Pauli decomposition combines the polarimetric channels to emphasize different scattering mechanisms:

  • Red: HH − VV (double-bounce scattering)

  • Green: HV (volume scattering)

  • Blue: HH + VV (surface scattering)

This composite is commonly used to distinguish scattering behavior across different land cover types.

filtered_C3 = os.path.join(
    in_file.split(".h5")[0],
    f"rlee_{window_size}x{window_size}",
    "C3"
)

pst.pauli_rgb(filtered_C3, save_tif=True)

7. Create an HH/HV/VV RGB Composite¶

This composite assigns each polarization channel directly to a color:

  • Red: HH

  • Green: HV

  • Blue: VV

Unlike the Pauli decomposition, this visualization displays the relative backscatter intensity of each polarization channel without combining them into scattering mechanisms. It is useful for examining differences in vegetation structure, surface roughness, and moisture while preserving the original polarization information.

Comparing Composites

This notebook produces both a Pauli RGB Composite and a HH/HV/VV RGB Composite

Both images use polarimetric SAR information to create an RGB visualization, however, they display information differently.

The HH/HV/VV composite assigns individual polarization channels directly to the red, green, and blue channels. The resulting colors show differences in the relative strength of the HH, HV, and VV radar returns. This provides a relatively direct view of the measured polarimetric backscatter.

The Pauli composite does not assign the individual HH, HV, and VV channels directly to colors. Instead, it combines the polarization measurements into components that emphasize different scattering behaviors. This makes differences in scattering behavior easier to distinguish visually.

In summary, the HH/HV/VV composite shows the polarization measurements more directly, while the Pauli composite reorganizes those measurements to emphasize differences in how the radar signal interacts with the surface.

import numpy as np
import rasterio
from rasterio.warp import calculate_default_transform, reproject, Resampling

def prepare_rgb_overlay(tif_path):

    with rasterio.open(tif_path) as src:
        transform, width, height = calculate_default_transform(
            src.crs,
            "EPSG:4326",
            src.width,
            src.height,
            *src.bounds,
        )

        rgb = np.zeros((3, height, width), dtype=np.uint8)

        for band in range(3):
            reproject(
                source=rasterio.band(src, band + 1),
                destination=rgb[band],
                src_transform=src.transform,
                src_crs=src.crs,
                dst_transform=transform,
                dst_crs="EPSG:4326",
                resampling=Resampling.nearest,
            )

    rgb = np.moveaxis(rgb, 0, -1)

    # Make pixels with no RGB values transparent
    alpha = np.where(np.any(rgb > 0, axis=2), 255, 0).astype(np.uint8)
    rgba = np.dstack((rgb, alpha))

    west = transform.c
    north = transform.f
    east = west + transform.a * width
    south = north + transform.e * height

    bounds = [[south, west], [north, east]]

    return rgba, bounds

10. Summary¶

You have now learned how to process full-polarimetric NISAR GSLC data using polsartools. This workflow demonstrated how to extract the C3 covariance matrix, reduce speckle with the Refined Lee filter, generate Pauli RGB and HH/HV/VV RGB composites, and create a high resolution spatial subset for more detailed polarimetric analysis.

Note: This workflow processes NISAR GSLC data for polarimetric analysis, but it does not perform radiometric terrain correction or create a GCOV-equivalent product. Users who require radiometrically terrain-corrected backscatter should consider using a NISAR GCOV product.
